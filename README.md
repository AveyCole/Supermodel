# Supermodel 3.70 audio test

30-second recording of six stock machines (Kick, Snare, Metal, Perc, Tone, Chord), HALL, Ping-Pong and LOW cutoff changes, recorded through ZOOM L6max input6L/R. Hardware peak85, zero forced cuts/overruns in this run. This is not the original user stress pattern/sound configuration and is not proof of a105-to85 matched improvement.

MP3 has a fixed30dB listening gain added for phones; no compression, EQ or noise reduction. WAV retains the recording level, converted from32-bit integer to16-bit PCM for compatibility.

No firmware or release files are published on this branch.
